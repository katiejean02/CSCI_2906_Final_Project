# CSCI_2906_Final_Project
This repository will hold the different phases of my final project at SouthWest Technical College. 
My goal with this program originally was to create a battleship game that connected through a server so multiple people could play simultaneosuly. The biggest issue I ran into with that was I couldn't get the server to get the Object of points for the boats once they were set in place. I needed this because in order to cross check when a player took a shot at their oppenents board I needed the points of the ships. Instead I ended up using a text file to write the points too which made them more easily accessible. I created an action to give me the points of the scene wherever the mouse clicked so I could get the points of every square in the board. Everytime you click a button to take a shot on your opponent, the progran reads the points of the players boats and cross checks them with the points of the button they pushed, resulting in the text area being set to either "you hit!" or "you missed". I am very proud of this project even though I still have some debugging to do.
